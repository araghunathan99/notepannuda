Sync between devices

How direct sync works

Pair your devices once with the code. Whenever the apps are open, they find each other through public relays (Nostr) and then connect directly, even on different networks. Normally your notes go straight from device to device, encrypted, and the relays only pass along short introductions.

The phone syncs while NotePannuda is open on it. Leave NotePannuda open on your computer and your phone catches up within seconds each time you open it. Some locked-down networks (offices, hotels, some mobile carriers) block direct connections. Then, while both devices are online, small changes go through the relays instead, still sealed with your pairing key so the relays can't read them, and never stored. Big catch-ups go slowly that way to be fair to the volunteers who run relays, so Send changes below is faster for those. It switches back to a direct connection as soon as the network allows.

More than two devices: pair each new device with the code from any device already in the group. Each device connects to every other one that's open. If two of them can't reach each other directly, a device in between passes changes along, so the whole group stays in sync. Devices that are rarely open at the same time still catch up through the others.

If the same jot is edited on two devices before they sync, both versions are kept and you choose. Changes to different fields, like a due date on one device and a priority on the other, simply combine.

Send changes, export and import

Save everything to a file and move it any way you like: Google Drive, Files, email, Quick Share. Importing a backup brings back everything in it that's missing here, including jots you deleted forever; importing an older or repeated file never loses anything.

If a share link opened in a different browser than the one you use for NotePannuda, paste it here.

Invite someone

Send a link to NotePannuda so someone else can install their own copy. It's just the app: none of your notes go with it, and it doesn't pair their device with yours. Once they have it, you can share jots with them.

Notifications

Get a note when another device connects and a daily summary of tasks due. On a Mac, keep NotePannuda open (minimized is fine) and alerts arrive as normal notifications. On a phone, they arrive while the app is open or recently used; Android pauses web apps in the background, so a due alert may wait until you next open it.

Jot box on a phone

You can also tap or swipe down the small handle above the jot box to hide it.

Enter key in the jot box

Automatic: on a phone or tablet, Enter adds a new line and the Note / Task buttons save; with a keyboard, Enter saves and Shift+Enter adds a new line. ⌘+Enter always saves as a task.

Auto-tag rules

One rule per line: tag: keyword, keyword, keyword. A jot containing any keyword gets the tag. Keywords match the start of words, so invoic catches invoice and invoicing.

Data

Deleted jots stay in Recently deleted (in the menu) for 30 days so you can restore them, all at once, by tag, or one by one. Delete forever there erases a jot's text right away instead of waiting, on all your paired devices.

Share with someone: select jots (search or filter first to narrow them down), then choose Share… (an open jot has it too). Share link sends a link with the jots inside: tapping it asks them to import the jots into their own NotePannuda. For big batches, share or download a file instead; on Android they share the file to NotePannuda, on a computer they drop it onto the window or use Import file. Only those jots go, without reminders, and your devices stay unpaired. Sharing an updated version later updates their copy.

Export file saves your notes as a backup (deleted jots are left out). Importing a backup restores what's in it: jots deleted forever come back, and jots still in Recently deleted stay there until you restore them (the import offers to). Send changes is sync by file: it also carries deletions, so importing it on another device removes what you deleted here.

Delete everything deletes your jots on this device and on all paired devices (you can undo it, or restore from Recently deleted). Reset this device unpairs this device and erases NotePannuda from it only; your other devices keep everything, and pairing again copies it all back.

Shortcuts and quick syntax

Enter save jot, Shift+Enter new line, ⌘+Enter save as task, / search, N new jot, T toggle task on selected, X complete selected task, S sort options, ⌘/Ctrl-click to select jots (long-press on a phone), Shift-click to select a range, ⌘+A select all, Delete delete selected, Manage tags in the selection bar adds tags to the selected jots, or removes one tag or all of them, X complete selected, J/K move selection, Esc close. Drag the edge of the sidebar or editor to resize it; double-click the edge to reset.

In a jot: #tag, !h !m !l (or !1–!3) for priority, due:today, due:fri, due:+3d, due:2026-10-12, w:1–w:5 for weight. A priority or due date turns the jot into a task.

Checklists: tap the checklist button in the jot box, or start lines with [] or - [ ]. Enter starts the next item, Enter on an empty item ends the list. A jot with a checklist is saved as a task, and checking the last item completes it.

In search: is:task is:note is:done is:open, p:high or several at once like p:high,med, due:overdue|today|week|none, w:3, w:2,3, w:3-5, w:none, #tag, -word, "exact phrase", sort:due sort:-priority sort:match sort:weight sort:edited sort:az.

Point the camera at the pairing code on your other device.
